# 원본 대비 수정사항

`upstream/yuhuizhai/`는 보관용 원본이고 `src/drt_abm/`이 실행 코드입니다.

| 영역 | 수정 | 이유 / 정책 영향 |
|---|---|---|
| import / 의존성 | 패키지 상대 import, 쓰이지 않는 tqdm 제거, PuLP를 전역 재배치에서만 import | 설치되지 않은 모듈을 흉내 내는 대체 모듈 없이 단일 구역 실행 |
| 난수 | City의 OD·차량 위치 RNG 분리, 도착 seed 외부 전달, 차량 ID 순 정렬 | 같은 요청으로 차량 수·정책 비교 가능 |
| 수요 | lmd=0 허용, T 이상 요청 제외 | 빈 수요 실행, 기간 내 수요 분모 일치 |
| 큐 | 요청시각·ID 순 힙, 빈 큐 안전 처리 | 마지막 요청 처리 후 오류 방지 |
| 서비스 반복 | 공통 스케줄러, 고유 요청 카운터, 한 객체 재실행 금지 | 상태 누적 재사용과 batch 중복 집계 방지 |
| 배치 | 유휴차량 0대여도 요청 재삽입, 빈 배치 평균 처리 | 공급 부족 시 요청이 사라지던 오류 수정 |
| 우회거리 | d(O,P)+d(P,D)-d(O,D), 공간 유형별 metric 사용 | 모든 방향에서 올바른 삽입 추가거리 |
| 합승 상태 | 추가 승객 t_a·status 기록, 실제 동승 경험 별도 기록 | 대기시간 계산과 shared 지표 해석 보완 |
| 차량 경로 | 마지막 하차 후 경로 정리, Euclidean 중간 정차 처리 통일 | 오래된 경로 누적과 합승 중 픽업점 하차 처리 방지 |
| Manhattan 이동 | x축 이후 남은 거리로 y축 이동 | 직교 회전에서 이동량을 버리지 않음 |
| 거리 기록 | 좌표에서 실제 이동량 계산, 유휴 이동거리 추가 | 도착 스텝에 speed×dt를 과대 누적하는 현상 방지 |
| 유휴 정책 | lr=False에서 현재 위치 유지 | 원본 idle_postion 오타와 초기위치 복귀 동작을 명시적으로 수정 |
| swap | Passenger.vehicle 갱신 | 교환된 차량 ID 기록 일치 |
| 다중 구역 | 초기화 인수 수정, 구역별 seed·속도·원점 전달, 목적 구역 재배치 위치 수정, 인접 판정 수정 | 초기화 후 gr=False의 소규모 상태 보존 검사 수행 |
| 도로망 | 원본 XLS 정규화, ID·끝점·연결성 검사, SQLite DB | 네트워크 입력을 검토 가능한 형태로 보관 |
| 미지원 경로 | real-world Simulation은 NotImplementedError | 차량이 정지해 있는데 완료된 실행처럼 보이는 상황 방지 |
| 출력 | 요청·승객·차량·시간별 상태·궤적 CSV, XLSX, SQLite, PNG, GIF, 실행 메타데이터 | 결과 확인·재현·추가 분석 |

## 유지한 가정

- 고정 속도, 고정 시간 스텝, 정사각형 내 균등 OD, 지수분포 도착 간격.
- 서비스 중 차량에 가능한 합승을 우선. 유휴 차량과 서비스 차량 비용을 전역 비교하는 정책이 아님.
- 고정 삽입 순서 `현재 위치 → 새 픽업 → 새 하차 → 기존 하차`.
- 한 번에 등록 승객 최대 2명. 새 승객 픽업 전에도 등록 수에는 포함.
- 우회 상한은 각 삽입의 남은 경로 증가량. 승객 전체 여행의 누적 우회율 제한이 아님.
- 한 스텝 안에서 여러 정차를 연속 처리하지 않으므로 픽업·하차 시각은 시간 해상도에 따라 양자화됨.
- T에서 종료하며 미완료 승객을 자동으로 끝까지 운송하지 않음.

## 아직 검증하지 않은 부분

PuLP/CBC를 사용하는 다중 구역 global reallocation, 원본 GUI, 버스 모듈, 대규모 다중 프로세스 예제 및 `opt_data/error`의 분석식은 검증하지 않았습니다. 기본 CLI는 이러한 기능을 호출하지 않습니다. 다중 구역 실험에 대한 완성된 지원이나 실제 도로망 합승 구현으로 해석하지 마십시오.
